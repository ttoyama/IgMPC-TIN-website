# IgMPC-TIN-website

IgM陽性形質細胞を伴う尿細管間質性腎炎 (IgM-positive plasma cell-rich tubulointerstitial nephritis; IgMPC-TIN) の情報サイト。

## ファイル構成

- `index.html` — トップページ（疾患紹介、研究紹介、関連文献、連絡先）
- `style.css` — スタイルシート

## 公開

GitHub Pages を利用して `igmpc-tin.com` で公開。

## ローカル確認

```sh
python3 -m http.server 8000
```

その後ブラウザで `http://localhost:8000` を開く。
